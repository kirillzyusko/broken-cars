# Host intro

`host-loading.mp4` is a 1080p H.264 copy of the supplied `d5327001e51e4477b41508babc7d7566.mp4`. It runs muted so browsers can start it automatically alongside the game's music. The poster comes from the same clip at 5.5 seconds.

The home page and host page show it once per tab session. Player routes and map pages do not mount or download the video. The host can skip it with the button or Escape. Reduced-motion mode shows the still poster. Playback errors and a timeout let the host continue if the video cannot finish.
