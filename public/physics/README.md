# Ammo runtime

Local copies of PlayCanvas's Ammo distribution, downloaded September 15, 2026.
The game loads these files from its own server and needs no physics CDN.

- https://developer.playcanvas.com/assets/modules/ammo/ammo.wasm.js
- https://developer.playcanvas.com/assets/modules/ammo/ammo.wasm.wasm
- https://developer.playcanvas.com/assets/modules/ammo/ammo.js

Ammo.js ports Bullet Physics to JavaScript and WebAssembly under the zlib license.
