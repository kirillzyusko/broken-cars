# Corsica GP

Exported from `art/monza-island/isola-grand-prix-platforms.blend`.

- `visual.glb`: complete map, embedded textures, shared meshes and GPU instances.
- `collision.glb`: 40 static triangle-mesh chunks. No render materials.
- `track.json`: closed route, start pose, collision policy, instance bounds and export counts.

Units are meters. Y is up. The start line is at the origin, facing negative Z.
The full lap is 500 meters. The track stays flat; the scenery has elevation.

Kenney created the asset packs under CC0. Original pack licenses are in `licenses/`.
Sponsor graphics came from the project's `art/assets/` folder and retain their original ownership.
